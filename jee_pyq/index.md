## Suggested file layout

Each year folder can contain:

- `README.md` — overview of available JEE Main and Advanced papers
- `meta.json` — metadata for the year
- `jee-main/` — JEE Main papers and solutions
- `jee-advanced/` — JEE Advanced papers and solutions
- `physics.pdf`, `chemistry.pdf`, `maths.pdf`, `solutions.pdf` — if official papers are added

## Example metadata

```json
{
  "year": 2024,
  "exam_types": ["JEE Main", "JEE Advanced"],
  "subjects": ["Physics", "Chemistry", "Mathematics"],
  "status": "placeholder",
  "notes": "Add official or legally shareable question papers here."
}
```

## Notes

- Use only materials you are legally allowed to upload.
- If you add scanned PDFs, include source attribution in `meta.json` or the file name.
- This structure is designed to support later automation or a web-based paper index.
